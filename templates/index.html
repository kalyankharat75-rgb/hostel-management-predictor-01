Core System Differentiators

Key modules addressing everyday hostel maintenance friction

🔍

1. Duplicate Issue Alert

Pre-checks active complaints filed for the same asset within the last 7 days. Prevents redundant tickets with Yes/No verification options.

Test Duplicate Alert →
🔒

2. Anonymous Complaint Mode

Students can file issues privately. Submitter name is masked in warden records as "Anonymous Student, Room {Room_No}" while keeping the room location intact for repairs.

File Private Ticket →
🗺️

3. Visual Room Heatmap

Interactive grid representing all floors and rooms color-coded by 30-day ticket density: Green (0-1), Yellow (2-3), and Red (4+ Hotspot). Click any room tile to inspect assets!

Open Visual Heatmap →
📈

4. Trend-Based Prediction

Harnesses Pandas 3-month simple moving averages (SMA) per room and floor to forecast upcoming failure surges (e.g., Room 204: 2 → 3 → 5 → Projected 6-8).

View Trend Forecast →
⚡

5. Impact Score Prioritization

Formula: affected_students × severity_weight (Electrical=3, Plumbing=2, Other=1). Automatically elevates urgent hazards to the top of the queue.

Open Admin Dashboard →
🚨

6. Asset Replacement Flagging

Automated policy flags any appliance with ≥ 3 complaints in 6 months (such as Fan-1 in Room 204) with a pulsing replacement badge to stop wasteful repeat repairs.

Inspect Replacement Units →
